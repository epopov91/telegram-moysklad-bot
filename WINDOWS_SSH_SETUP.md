## 🔧 Одноразовая настройка (через AnyDesk)

### Шаг 1: Установка OpenSSH на Windows

1. **Откройте PowerShell от имени администратора:**
   - Нажмите Win+X
   - Выберите "Windows PowerShell (Администратор)" или "Терминал (Администратор)"

2. **Установите OpenSSH Server:**
   ```powershell
   Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
   ```

3. **Запустите SSH сервис:**
   ```powershell
   Start-Service sshd
   ```

4. **Настройте автозапуск SSH:**
   ```powershell
   Set-Service -Name sshd -StartupType 'Automatic'
   ```

5. **Разрешите SSH в брандмауэре:**
   ```powershell
   New-NetFirewallRule -Name sshd -DisplayName 'OpenSSH Server (sshd)' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
   ```

### Шаг 2: Узнайте IP адрес Windows компьютера

В PowerShell выполните:
```powershell
ipconfig
```

Найдите строку **IPv4 Address** - это IP адрес вашего Windows компьютера в локальной сети.
Например: `192.168.1.100`

**Скопируйте этот IP адрес** - он понадобится для подключения.

### Шаг 3: Узнайте имя пользователя Windows

```powershell
echo $env:USERNAME
```

Запишите это имя пользователя.

### Шаг 4: Создайте или узнайте пароль

Если у вашего пользователя Windows нет пароля, создайте его:
1. Win+R → `control userpasswords2` → Enter
2. Выберите своего пользователя
3. Установите пароль

**Важно:** SSH требует пароль для подключения.

### Шаг 5: Установите Python на Windows (если еще не установлен)

1. Скачайте с https://www.python.org/downloads/
2. При установке поставьте галочку **"Add Python to PATH"**
3. Проверьте: `python --version`

### Шаг 6: Установите Git на Windows (если еще не установлен)

1. Скачайте с https://git-scm.com/download/win
2. Установите с настройками по умолчанию
3. Проверьте: `git --version`

## 🔒 Безопасность

- SSH подключение работает только в вашей локальной сети
- Для доступа из интернета нужна дополнительная настройка (проброс портов)
- Рекомендуется использовать SSH ключи вместо пароля (можем настроить позже)

## ❓ Если что-то пошло не так

**SSH не запускается:**
```powershell
Get-Service sshd
```
Должно показать "Running"

**Не можете подключиться:**
- Проверьте, что оба компьютера в одной сети
- Проверьте брандмауэр Windows
- Убедитесь, что используете правильный IP адрес

**"Permission denied":**
- Проверьте имя пользователя и пароль
- Убедитесь, что у пользователя есть пароль
