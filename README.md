# Telegram Bot для загрузки фото в МойСклад

Телеграм бот для удобной загрузки фотографий товаров в систему МойСклад по артикулу модификации.

## 🚀 Возможности

### Основные функции:
- Поиск товаров по артикулу в МойСклад
- Загрузка фотографий к модификациям товаров  
- Загрузка видео в Google Drive (по цвету товара)
- Просмотр существующих фотографий товара
- Удобная клавиатура с кнопками управления

### Админ-функции (v2.0.0):
- 🔄 **Автообновление** - обновление кода из GitHub через Telegram
- 📊 **Статистика** - количество загрузок, uptime, версия
- 📋 **Логи** - просмотр логов работы прямо в Telegram
- 💾 **Бэкап фото** - опциональное сохранение всех фото на диск
- 🗄️ **База данных** - история всех загрузок с метаданными
- 🔐 **Авторизация** - защита админ-команд по Telegram ID

## 📋 Требования

- Python 3.7 или выше
- Токен Telegram бота (получить у [@BotFather](https://t.me/BotFather))
- API токен МойСклад

## 🔧 Установка на VPS (Ubuntu)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/epopov91/telegram-moysklad-bot.git
cd telegram-moysklad-bot
```

### Шаг 2: Настройка окружения

1. Создайте файл `.env` в папке с ботом:
   ```bash
   nano .env
   ```

2. Добавьте ваши токены:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   MOYSKLAD_API_TOKEN=ваш_токен_МойСклад
   ADMIN_USER_ID=ваш_telegram_id
   GOOGLE_DRIVE_ROOT_FOLDER_ID=id_корневой_папки
   ```
   
   **Для загрузки видео в Google Drive:**
   - Скопируйте файлы `credentials.json` и `token_drive.json` в папку с ботом
   - Или настройте OAuth2 авторизацию Google Drive (см. инструкцию в папке "Google таблица/OAUTH2_DRIVE_SETUP.md")

### Шаг 3: Установка зависимостей

```bash
pip3 install -r requirements.txt
```

### Шаг 4: Запуск бота

```bash
python3 tg_ms_uploader.py
```

Или используйте systemd сервис (см. `setup_vps.sh`).

## 🔄 Обновление бота

Когда код обновится в GitHub, на сервере выполните:

```bash

```

Затем перезапустите бота через команду `/restart` в Telegram или через systemd:
```bash

```

## 💡 Использование

### Для пользователей:
1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Выберите действие:
   - **📸 Загрузить фото** - загрузка фото в МойСклад
   - **🎥 Загрузить видео** - загрузка видео в Google Drive
4. Введите артикул модификации товара
5. Отправьте фото/видео для загрузки
6. Используйте кнопки для навигации:
   - **✅ Завершить** - завершить загрузку
   - **🔄 Другой товар** - переключиться на другой товар
   - **🔙 Главное меню** - вернуться в главное меню

### Для администратора:
- `/admin` - список всех админ-команд
- `/status` - статус бота, статистика, uptime
- `/logs` - последние 50 строк логов
- `/backup_on` - включить сохранение фото на диск
- `/backup_off` - выключить сохранение фото
- `/update` - **обновить код из GitHub и перезапустить**
- `/restart` - перезапустить бота

## 🐛 Решение проблем

**Бот не запускается:**
- Проверьте, что файл `.env` создан и содержит правильные токены
- Убедитесь, что установлены все зависимости: `pip3 install -r requirements.txt`
- Проверьте логи: `journalctl -u telegram-bot -f`

**Ошибки Google Drive:**
- Убедитесь, что файлы `credentials.json` и `token_drive.json` находятся в папке с ботом
- Проверьте права доступа к файлам: `chmod 600 credentials.json token_drive.json`

**Бот не отвечает:**
- Проверьте статус сервиса: `sudo systemctl status telegram-bot`
- Проверьте логи: `journalctl -u telegram-bot -n 50`
- Убедитесь, что токен Telegram правильный
- Проверьте интернет-соединение
