# 🚀 Быстрый старт - Управление ботом через Cursor AI

## Одноразовая настройка (5 минут)

### На Windows (через AnyDesk - ПОСЛЕДНИЙ РАЗ!)

1. **Скачайте этот PowerShell скрипт из репозитория:**
   https://github.com/epopov91/telegram-moysklad-bot/blob/main/setup_windows_ssh.ps1

2. **Запустите его от имени Администратора:**
   - Правой кнопкой по файлу
   - "Запустить с PowerShell"
   - Если система спросит, разрешите выполнение

3. **Скопируйте данные из вывода скрипта:**
   - IP адрес
   - Имя пользователя
   - Ваш пароль Windows

4. **Отправьте мне в Cursor эти данные**

5. **Закрывайте AnyDesk - больше не понадобится!** 🎉

- ✅ SSH работает только в вашей локальной сети
- ✅ Токены хранятся в .env (не в Git)
- ✅ Приватный GitHub репозиторий
- ⚠️  Для доступа извне сети нужна дополнительная настройка

## Решение проблем

**"Connection refused"**
- Проверьте, что Windows включен
- Проверьте, что SSH сервис запущен на Windows
- Убедитесь, что оба компьютера в одной сети

**"Permission denied"**
- Проверьте пароль
- Убедитесь, что у пользователя Windows есть пароль

**Бот не запускается на Windows**
- Проверьте, что Python установлен
- Проверьте, что установлены все зависимости
- Проверьте правильность токенов в .env
